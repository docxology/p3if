# Discussion

An unobserved coordinate locates a position in the declared space.
Assessing its importance requires additional domain evidence. A change
report measures the fields supplied by the snapshot producer. It can
locate an endpoint change while ownership, timing, and the adequacy of a
declared relationship require independent evidence.

The manuscript uses the shipped domain and an explicit synthetic edit.
The preregistrations and retained reviewer results address separate
questions about how people or models read these records. This experiment
covers the deterministic interchange and change reports.
