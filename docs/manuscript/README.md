# P3IF methods

The [interchange methods note](METHODS.md) defines the measurements and provides commands to reproduce a domain-library census and a controlled revision comparison. The [ScienceResearch editorial audit](scienceresearch-audit.md) applies those methods to a public worked case and proposes a reviewer study. The [manuscript status](MANUSCRIPT_STATUS.md) records the publication posture.

The [reviewer study preregistration](reviewer-study-preregistration.md) freezes the cases and scoring rules and separates the technical pilot from the planned human study.


The [technical reviewer pilot](reviewer-study-pilot.md) reports the two-domain crossover and provides the raw submissions and reproducible scores.

The [held-out conformance follow-up](held-out-conformance.md) verifies compound changes, transport identity, and exact citations across 16 new snapshot pairs. Its [registration](held-out-preregistration.md) and receipts let readers reproduce the technical checks.

The [masked held-out model comparison](held-out-reviewer.md) archives four independent model submissions, the packet inventory, and the matched results for P3IF audit and transition versus a stable-ID diff.

The [citation accuracy and review effort comparison](citation-effort-results.md) publishes four masked model sessions on new revisions, their raw reader logs, and exact reproduction commands.

The [source navigation ablation](navigation-ablation-results.md) isolates the navigation array on fresh held-out revisions and publishes exact citation scores, measured reader effort, and live FOLIO verification.
