# P3IF methods

The [interchange methods note](METHODS.md) defines the measurements and provides commands to reproduce a domain-library census and a controlled revision comparison. The [ScienceResearch editorial audit](scienceresearch-audit.md) applies those methods to a public worked case and proposes a reviewer study. The [manuscript status](MANUSCRIPT_STATUS.md) records the publication posture.

The [reviewer study preregistration](reviewer-study-preregistration.md) freezes the cases and scoring rules and separates the technical pilot from the planned human study.


The [technical reviewer pilot](reviewer-study-pilot.md) reports the two-domain crossover and provides the raw submissions and reproducible scores.
