# AGENTS.md — `docs/manuscript/`

The manuscript record: `MANUSCRIPT_STATUS.md` states the posture of the paper draft
associated with this repository — what exists, what is blocked, and what the next
step is.

- It is a status record, not a draft: there is no LaTeX or Word source in this
  folder, and no build produces one. The docs-tree guide points here precisely so the
  manuscript question has one answer.
- Keep it dated and factual when the posture changes; a status file that is not
  updated is worse than none, because nothing else tracks this.
- No test, CI job, or generator reads or writes it.

Docs-tree guide: [`../AGENTS.md`](../AGENTS.md); repository rules:
[root guide](../../AGENTS.md).
