# P3IF manuscript status

Updated 2026-11-09.

P3IF maintains a technical [interchange methods note](METHODS.md) in this repository. It specifies the measurement and comparison procedures, reproduces descriptive results from a shipped domain, and checks a controlled synthetic revision. Its evidence concerns the declared graph and the behavior of the software.

A publication study would need a defined research question, reference annotations or another independent criterion, and a protocol for comparing how different modeling workflows perform. The current repository artifacts support reproduction of the graph measurements.
