# P3IF

P3IF describes systems through Properties, Processes, and Perspectives.
Use its Python API and command-line tools to validate snapshots, count
declared relationships, compare revisions, and visualize changes.

- [Read the package guide](docs/package-guide.md) for installation and usage.
- [Browse the documentation](docs/README.md) and [versioned interchange](docs/interchange.md).
- [Build the manuscript](docs/manuscript/README.md) from the shipped domain and synthetic archive fixture. The fixture checks archive handling and does not measure external systems.

Requires Python 3.13 or newer. [Release history](docs/releases/CHANGELOG.md) · [MIT License](LICENSE)
